# clip-zero-shot-image-classification
<!-- File: README.md -->

学習済みのCLIPを使って、画像を任意の候補ラベルに分類するGoogle Colab向けのデモです。

画像と各ラベルの類似度を比較し、最もスコアが高いラベルと、全候補の相対スコアを表示します。分類にあたって、モデルの追加学習は行いません。

## 機能

- 画像のアップロードとプレビュー表示
- 候補ラベルのカスタマイズ
- CLIPによるZero-shot画像分類
- 候補ラベルごとの相対スコア表示
- GPU／CPUの自動選択
- ファイル未選択・複数選択・画像読み込み失敗への対応
- 空のラベルや重複ラベルの検証

## 使用技術

- Python
- PyTorch
- Hugging Face Transformers
- Pillow
- Google Colab

**使用モデル：** `openai/clip-vit-base-patch32`

モデルの重みは実行時にダウンロードします。リポジトリには含めません。

## ファイル構成

- `README.md`：プロジェクトの概要と実行手順
- `clip_zero_shot.ipynb`：画像分類を実行するノートブック

## 実行方法

1. `clip_zero_shot.ipynb` をGoogle Colabで開きます。
2. 必要に応じて、Colabの「ランタイム」→「ランタイムのタイプを変更」からGPUを選択します。
3. ノートブックのセルを上から順に実行します。
4. 候補ラベルを設定します。
5. 最後のセルで画像を1枚アップロードします。
6. 表示された画像・予測ラベル・相対スコアを確認します。

別の画像を分類する場合は、最後のセルを再実行してください。候補ラベルを変更した場合は、ラベル設定セルも再実行してください。

### 実行環境について

- Google Colab向けの実装です。ローカル環境では、画像アップロード処理の変更が必要です。
- GPUは必須ではありません。利用できない場合はCPUで動作します。
- 依存ライブラリのインストールとモデルの初回取得には、インターネット接続が必要です。
- ノートブック内のインストール処理では、依存ライブラリのバージョンを固定していません。環境によって互換性の問題が発生する可能性があります。

## 候補ラベル

初期設定では、次の5種類を使用します。

| ラベル | 意味 |
|---|---|
| car | 車 |
| apple | リンゴ |
| house | 家 |
| cat | 猫 |
| dog | 犬 |

ノートブックの `labels` を編集すると、比較するカテゴリを変更できます。

このモデルでは、まず英語のラベルを使うことを想定しています。候補を変更しても再学習は不要ですが、任意のカテゴリを正確に認識できることを保証するものではありません。

## 処理の仕組み

1. **前処理**  
   `CLIPProcessor` により、画像のサイズ調整・正規化と、候補テキストのトークン化を行います。

2. **特徴抽出と比較**  
   CLIPが画像とテキストを共通の特徴空間へ変換し、類似度に基づくスコアを計算します。

3. **スコアの正規化**  
   Softmaxを使って、候補ラベルのスコアの合計を1にします。

4. **結果の表示**  
   最大スコアのラベルを予測結果として表示し、全候補をスコアの高い順に並べます。

Zero-shotとは、今回の分類課題に対して追加の学習例を与えずに推論することです。CLIP自体は、事前に画像とテキストの組を使って学習されています。

## 実装上の工夫

- モデルと入力を同じデバイスに配置し、GPUが利用可能な場合に活用します。
- `model.eval()` で評価モードを指定します。
- `torch.inference_mode()` によって、推論に不要な勾配追跡を無効にします。
- 画像のEXIF情報に基づいて向きを補正し、RGB形式に統一します。
- 分類処理を `classify_image()` に分離しています。
- 公開用ノートブックから、保存済みの出力や不要な実行メタデータを除去しています。

## 制約と注意点

### スコアは正しさを保証する確率ではありません

表示値は、指定した候補ラベル間での相対スコアです。例えば99%と表示されても、現実にそのカテゴリである確率が99%だと保証されるわけではありません。

候補の追加・削除・表現の変更によって、スコアは変化します。

### 正解が候補にない場合も分類されます

この実装には「該当なし」を自動判定する機能がありません。画像がどの候補にも当てはまらない場合でも、最もスコアが高い候補を選びます。

### 画像全体を分類します

画像中の物体の位置を示す物体検出や、画素単位の分類は行いません。複数の物体が写っている場合も、画像全体に対して候補を比較します。

### 性能評価について

このリポジトリは推論デモです。特定の評価データセットに対する正解率は提示していません。
